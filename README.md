# Список задач

Простое веб-приложение To-Do List на HTML, CSS и JavaScript.

## Возможности
- Добавление, отметка выполненных и удаление задач
- Сохранение задач в localStorage (не пропадают после обновления страницы)
- Фильтры: все / активные / выполненные
- Адаптивный дизайн и тёмная тема

## Запуск
Откройте `index.html` в браузере.
